# 사이 · 취향이 만나는 곳

흰 배경과 검은 글씨의 iOS / Android 앱. 친구 두 명 또는 모임 참여자의 **공통 관심사와 연결 후보**를 보여줍니다. 대화 질문을 생성하지 않습니다.

## 실행

Node.js 24 이상에서 `npm install` 후 `npm run server`를 실행하세요. `.env`에 `EXPO_PUBLIC_API_URL=http://컴퓨터의LAN주소:8788`을 지정하고 `npm start` 후 휴대폰 Expo Go로 QR을 스캔합니다. 휴대폰과 컴퓨터가 같은 Wi-Fi에 있어야 합니다. 개발 빌드 및 설치 파일 안내는 [mobile/README.md](mobile/README.md)에 있습니다.

## 구현한 기능

- 공유 여부를 선택하는 관심사 프로필, 프로필 링크/QR
- 친구 요청·수락과 두 사람 비교
- 코드/링크로 참여하는 모임, 인원 상한 없음
- 동일 관심사·관련 분야 구분, 참여자와 원문 근거 표시
- 자유 입력의 관심사 추출: 웹에서 생성 모델을 실행하고 후보를 선택해 저장
- 기기 세션 저장, 서버 SQLite 저장, 프로필 삭제

## AI 설정

의미 비교는 Qwen3-Embedding-0.6B의 ONNX q8 배포본을 Transformers.js로 실행합니다. 웹에서는 공유 관심사를 Web Worker에서 계산하며 첫 분석에서 약 614MB의 모델 파일을 내려받습니다. PC 사용을 권장합니다. 로컬 Node 서버도 같은 Qwen3 모델을 사용합니다. 동일 관심사 정규화와 분야 규칙도 함께 사용합니다. 모델 점수는 실제 대화 가능성의 확률이 아닙니다.

무료 공개 가중치 LLM을 컴퓨터에서 실행하려면 Ollama로 모델을 준비한 뒤 `.env`에 `OLLAMA_URL=http://localhost:11434`, `OLLAMA_MODEL=qwen3:1.7b`를 설정하세요. 이 방식은 서버의 컴퓨팅 자원을 사용합니다. OpenAI를 사용하려면 서버에만 `OPENAI_API_KEY`를 설정합니다. ChatGPT 무료 계정은 API 권한을 제공하지 않습니다.


## 확인과 한계

`node backend/auth-smoke.mjs`, `node backend/preferences-smoke.mjs`, `node backend/taste-extraction-smoke.mjs`, `node backend/grouping-smoke.mjs`에서 가입·세션·공개 권한·생성 결과 검증·30명 그룹 편성을 확인합니다. TypeScript 검사와 웹 내보내기를 완료했습니다. 실제 iOS/Android 기기 실행·스토어 제출은 아직 하지 않았습니다. 계정 복구, Spotify/YouTube 계정 연동·주간 자동 갱신은 미구현입니다.

웹의 서버 Worker는 모델을 실행하지 않으며 브라우저에서 Qwen3를 실행합니다. 기본 태그·분야 비교는 모델 없이도 동작합니다. 웹의 문장 정리에는 서버 API 설정이 필요하지 않습니다. Instagram은 계정 핸들을 직접 등록하는 기능이며 OAuth 로그인이나 게시물 수집이 아닙니다. 공개 여부를 켠 경우에만 수락한 친구가 볼 수 있습니다.

## 문장으로 취향 정리

웹의 `문장으로 정리하기`/`말로 추가`는 Qwen3-0.6B 생성 모델(ONNX q8)을 별도 Web Worker에서 실행합니다. 서버 API 키가 없어도 사용할 수 있으며, 첫 실행에 약 614MB의 추가 모델 다운로드가 필요합니다. 공유 관심사 비교용 임베딩 모델과 별개의 모델입니다. 입력 문장은 브라우저에서 처리하고 저장하지 않으며, 사용자 확인 후 선택한 항목만 프로필 저장 과정에서 저장합니다. 생성 결과의 항목 이름은 입력 원문에 있는 것만 허용하며 질문별 선호 구분은 모델 추출과 사용자 확인을 거칩니다. 생성 모델의 분류/부정 이해가 완벽하다고 보장하지 않습니다. 오류·중단 시 직접 입력을 사용할 수 있습니다. 네이티브 앱의 기존 서버 추출 경로는 서버 LLM 설정이 필요합니다.

## 가입과 첫 프로필
- 아이디·비밀번호·비밀번호 확인으로 가입한 다음 전체 페이지에서 취향 프로필을 설정합니다. 비밀번호는 scrypt(N=32768,r=8,p=3)와 개별 salt로 저장하며 세션은 30일 후 만료됩니다. 로그인 시도는 15분에 5회로 제한합니다.
- AI 정리 모델은 Qwen3-0.6B ONNX q8을 브라우저에서 실행합니다. 첫 다운로드 약 614MB, 직접 입력도 가능합니다. 모델 저장은 브라우저 캐시 정책에 따라 달라집니다. 좋아함/회피/탐색 질문에 답하면 원문에 있는 후보만 제안하고 사용자가 선택해 저장합니다.
- Instagram 및 LinkedIn은 선택 프로필 등록 기능입니다. 각각 친구 공개를 켜고 서로 수락한 친구만 볼 수 있습니다. SNS 로그인이나 게시물/경력 자동 수집은 지원하지 않습니다.

## 모임 구성
채팅 기능 없이 모임 검색과 참여자 목록, 공통 관심사 랭킹, 소그룹 제안을 제공합니다. 랭킹은 참여자 수 우선, 동일 관심사 우선입니다. 소그룹은 모든 구성원 쌍에 접점이 있는 complete-link 방식으로 최대 3~6명을 묶습니다. 점수는 각 사람의 공유 긍정 취향 중 연결된 항목 비율의 양방향 평균입니다. 동일 항목=1, 관련 분야=0.6, AI 후보=임베딩 코사인값(0.75 이상)을 가중치로 사용합니다. 점수는 관계 성공 확률이 아니며, 연결 근거가 없는 사람은 배정하지 않습니다. AI 실행 전에는 기본 공통점, 실행 후에는 의미 유사도를 반영합니다. 공유 회피 항목은 추천에서 제외하고 비공개 항목은 비교하지 않습니다.

## 기존 DB 변경 기록 정합성
기존 공개 사이트의 Worker가 먼저 설치한 Instagram 컬럼은 배포 전 D1 스키마에서 확인했습니다. 아직 기록되지 않아 실패한 0001 마이그레이션은 해당 컬럼 존재를 검증하고 변경 기록을 등록하도록 수정했습니다. 운영 Worker는 스키마를 변경하지 않습니다. 신규 로컬 DB와 테스트에서는 기존 사이트의 기준 스키마를 먼저 준비합니다. 이 마이그레이션 기록은 해당 기존 Site를 기준으로 하므로 완전히 새로운 Site로 복제할 때는 별도의 초기 스키마를 준비해야 합니다.
